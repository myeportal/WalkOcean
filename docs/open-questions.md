# Walkocean Open Questions

## Highest-leverage questions
1. Who is the first specific user segment for Walkocean?
2. What painful problem does Walkocean solve often enough that users will install and keep it?
3. What is the smallest lovable v1 outcome?
4. How does Walkocean make money: paid app, subscription, in-app purchase, lead gen, or something else?
5. Is the app content-driven, utility-driven, community-driven, or marketplace-driven?
6. Does launch need a companion web landing page tied to the secured domain?
7. Should the initial build path be native, React Native, Flutter, or low-code wrapper?
