# Walkocean MVP Feature Map

## Phase 1: launchable local service

### Customer / family features
- landing page and trust-first booking funnel
- choose 30 or 60 minute walk
- select Whatcom County coverage area
- profile fields for pace, mobility, preferences
- emergency contact capture
- booking confirmation and reminders
- PayPal checkout
- crypto checkout option
- recurring subscription/package option

### Walker / operator features
- Kelly founder profile
- booking calendar
- check-in / check-out controls
- client notes and route preferences
- completion logging
- simple admin dashboard

### Trust / safety features
- background-check badge if applicable
- cancellation and refund clarity
- weather-aware scheduling
- family reassurance messaging

## Later phases
- multi-walker marketplace
- reviews and ratings
- family account layer
- route sharing / check-in visibility
- regional expansion
